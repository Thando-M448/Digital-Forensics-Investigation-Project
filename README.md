# Memory and Registry Forensics Investigation

## Project Overview

This repository documents a digital forensics investigation project completed as part of coursework in Cyber Security and Computer Forensics.

The project focused on Memory Forensics and Windows Registry Hive Forensics and was completed collaboratively by two students.

## Team Contributions

**Windows Registry Hive Forensics — Thando Msibi**

Focused on the examination and analysis of Windows Registry hive evidence as part of the investigation.

**Memory Forensics — Sixole Mkhonta**

Focused on the memory forensics component of the investigation.

## Project Objectives

The project provided an opportunity to apply digital forensics principles, examine digital evidence, document investigative procedures, and maintain appropriate evidence-handling records.

## Repository Contents

- **Report:** The investigation report documenting the project.
- **Evidence Documentation:** Chain of custody records and relevant evidence-integrity documentation.
- **Screenshots:** Selected visual previews of the report and investigation documentation.
- **Methodology:** Additional information about the investigative approach and tools, where available.

## Evidence Integrity

The investigation documentation includes chain of custody records and hashing information where applicable.

These records support the documentation and verification of digital evidence integrity.
